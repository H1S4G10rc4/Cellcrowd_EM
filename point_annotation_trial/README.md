# Current model

Start with the [repository guide](../README.md) for installation, tests and the
synthetic pilot. The current implementation is in `src/configuration_model.py`;
the earlier class model is isolated in `src/historical/`.

The English and Japanese Methods documents under `docs/` describe the current
configuration model. Saved research data, fitted parameters and rendered figures
are private and are not included. Historical audit commands need the original
local provenance and results; they are not clean-clone tests.
